# Questions and decisions

| Question | Decision |
| --- | --- |
| Is this a page redesign? | No. It is a focused replacement of the already approved static hero visual. Existing page sections and controlled copy remain. |
| What counts as the same operating truth? | The condition, affected asset, owner, work item, and current state stay identical in all three tabs. Only scope, diagram, and role-relevant measurements change. |
| Which role opens first? | PLANT MGR, matching the requested baseline facility view. |
| Can executive measurements combine several sites? | No. They are explicitly scoped to the one illuminated North Ridge Plant point. |
| May inactive executive locations glow? | No. Inactive sites use quiet grey outlines. Only the selected site receives the blue halo and active fill. |
| Does the exact blue replace the site-wide theme token? | No. `#1D7CD8` is scoped to the portal's active controls and data marks so the broader approved theme remains intact. |
| Are the displayed measurements customer results? | No. The portal remains clearly captioned as a concept interface and uses illustrative operating values. |
| Does role tuning change access or control authority? | No. This website interaction demonstrates presentation only. Existing permissions, equipment control, and safety boundaries do not change. |
