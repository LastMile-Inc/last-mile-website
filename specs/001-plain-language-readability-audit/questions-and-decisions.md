# Questions and decisions

| Question | Decision |
| --- | --- |
| Is this a redesign? | No. Preserve the current information architecture, compositions, imagery, components, and route order. |
| Which wording is safe to change? | Visible explanatory copy that is not a controlled claim. Controlled claim wording changes only through the repository authority chain. |
| Do technical names disappear? | No. Keep names users must recognize and explain them in ordinary language at first appearance. |
| Does the corporate site require an in-app User Guide? | No. This repository is a public corporate website, not the foundation application described in the original broad audit prompt. Existing Resources and Industrial Concepts provide public technical help. |
| How should ambiguous terms be handled? | Put the plain meaning first and retain the exact technical term only when recognition or claim precision requires it. |
