# Feature 001: Plain-language readability audit

## Purpose

Make the existing Last Mile website easier for a business founder to understand without redesigning it or changing any product claim, operating boundary, safety rule, calculation, source relationship, or customer control.

## User need

Readers should understand what happened, why it matters, and what to do next before they encounter optional technical detail.

## Scope

- Global navigation and public page headings, labels, buttons, captions, and helper text.
- Home, Platform, Infinit-Signal, Singularity, Infinit-Flow, Infinit-Control, Use Cases, Resources, and shared public components.
- Desktop, tablet, phone, keyboard, reduced-motion, and screen-reader behavior already supported by the site.
- Automated protection against retired specialist phrases in the main product-page workflow.

## Out of scope

- A redesign, new product behavior, new data handling, new integrations, deployment, merge, or infrastructure change.
- Changes to calculations, controlled reference measurements, saved formats, security boundaries, customer separation, permissions, ownership, or safety controls.

## Acceptance criteria

1. Main product pages lead with an outcome, consequence, or decision in ordinary language.
2. Unavoidable technical names are explained on first use where practical.
3. Retired specialist phrases do not appear in the main product-page workflow except in explicitly approved technical detail.
4. Existing navigation, accessible names, focus behavior, responsive layout, claims, and safety boundaries remain intact.
5. Copy-proximity, governance, editorial, type, lint, test, build, and whitespace checks pass.
