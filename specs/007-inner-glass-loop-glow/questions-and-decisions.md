# Questions and decisions

| Question | Decision |
| --- | --- |
| Should the commissioned image be replaced? | No. The image is approved; only the illumination method is defective. |
| Why remove clipped raster wedges? | Their polygon edges reveal large colored image blocks that cross the metal frame. |
| How is color kept beneath the glass? | A feathered SVG mask reveals the approved image only along a smooth glass-rail path, then a narrow gradient beam and soft bloom reinforce the light source. |
| Should the definition use a generic blue tint? | No. Use the exact light-to-dark gradient stops used by the active rail. |
| Does the animation timing change? | No. Evidence through Verify still runs once when visible, then returns to neutral. |
| Does Infinit-Control change? | No. The portal is approved and remains untouched. |
