# Questions and decisions

| Question | Decision |
| --- | --- |
| Should the Home loop structure be rebuilt? | No. Keep the approved three-column structure, definition spacing, original v3 image, and Flexbox centering. |
| What counts as removing the picture frame? | The Home figure has no border, radius, grey fill, white panel, shadow, hover treatment, or overflow clipping. |
| Should Condition, Response, and Outcome be redrawn over the image? | No. Remove the generated center oval and every image overlay. The commissioned image remains unobstructed. |
| Should role interaction be replaced? | No. Preserve the existing state-driven tabs and shared case facts. Replace only the low-detail visual surfaces and sparse panels. |
| How should the central views be produced? | Use three original, light-theme raster engineering plates with detailed CAD-style linework. Accessible HTML retains the role context and live indicators. |
| Is the Executive map allowed to highlight multiple locations? | No. It contains exactly one blue selected site; all other locations remain quiet grey. |
| Are the displayed values customer results? | No. The portal remains clearly identified as a concept interface, and the values illustrate role-specific presentation of one shared case. |
| Can the high-fidelity request change control or safety authority? | No. Existing equipment-control, permission, data, customer-boundary, and safety responsibilities remain unchanged. |
