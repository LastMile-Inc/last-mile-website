# Questions and decisions

| Question | Decision |
| --- | --- |
| Should the supplied dark portal be copied literally? | No. Copy its information density and panel hierarchy while translating every surface to the approved light palette. |
| Should the existing role images be replaced again? | No. They already provide the required plant, portfolio, and bottling-line detail. Rebuild the surrounding data system and retain the working image switch. |
| Are the displayed measurements customer results? | No. They are believable concept-interface values and remain labeled as a concept. |
| How should the loop image become interactive without replacing it? | Render the same commissioned image as a neutral base and as six clipped color layers aligned to the six physical metallic sections. |
| When should the opening sequence run? | Once when the loop first becomes visible, so a below-the-fold animation is not missed. |
| Can hover interrupt the opening sequence? | No. Pointer and focus selection take control only after the six-phase sequence returns to neutral. |
| What happens for reduced motion? | Skip the timed sequence, show the neutral ring, and make pointer and keyboard interaction available immediately. |
| Does this change operating authority or safety behavior? | No. The portal is presentation-only and does not change permissions, control, data, customer boundaries, ownership, or safety responsibilities. |
