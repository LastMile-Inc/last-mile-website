# Founder Review Rubric

Use this rubric for every major public-page review. A route is not ready merely because it builds.

## Message

- [ ] The page has one obvious job.
- [ ] The hero promise can be understood in five seconds.
- [ ] The hero passes the spoken-language test: a real operator or buyer could say it naturally.
- [ ] Public copy contains no em dashes.
- [ ] Public copy contains no em dashes.
- [ ] Real-world problems and results appear before internal platform terminology.
- [ ] Each major section introduces a distinct idea.
- [ ] Captions, proof lines, callouts, and diagram labels add information instead of restating neighboring copy.
- [ ] Copy is direct, concrete, and within its page contract.
- [ ] Product and architecture language matches controlled claims.
- [ ] References are not presented as customer deployments or ROI proof.

## Art direction

- [ ] The page has one strong, route-specific explanatory visual.
- [ ] The composition varies in scale and structure rather than repeating identical cards.
- [ ] Icons are substantial and meaningful, or omitted.
- [ ] The approved pale-blue, steel, grey, white, and ink palette is intact.
- [ ] Photography or generated imagery is authentic to the operating context and honestly framed.
- [ ] The page feels intentionally composed at desktop, tablet, and mobile sizes.

## Interaction and accessibility

- [ ] Reading and focus order remain logical at every viewport.
- [ ] Interactive information is available by keyboard and pointer.
- [ ] Focus is visible and Escape behavior restores focus where applicable.
- [ ] Visual meaning has an accessible HTML equivalent.
- [ ] Motion is restrained and reduced-motion safe.
- [ ] No horizontal overflow occurs at required review sizes.

## Restraint

- [ ] No section repeats the hero or another section.
- [ ] No decorative visual exists only to occupy space.
- [ ] No small-icon grid is carrying the primary story.
- [ ] No fake logos, customers, testimonials, adoption, ROI, or performance claims appear.
- [ ] No generic closing CTA or next-step panel has been added to fill the bottom of the page.

## Release evidence

- [ ] Canonical page contract is current.
- [ ] Controlled-content validation passes.
- [ ] Type checking, lint, tests, and production build pass.
- [ ] Changed code and assets pass the palette audit.
- [ ] Responsive review results and deliberate deviations are recorded.
