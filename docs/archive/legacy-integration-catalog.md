# Legacy integration catalog disposition

Date: 2026-08-10

The website's inactive integration catalog, generated API artifacts, scrapers, and catalog UI were removed from the active tree in Phase 4. The material belongs to an earlier ServiceNow-focused company chapter and does not define the independent Last Mile Platform.

Before removal, a complete dated recovery archive was created. Git history also preserves the exact source material. The archive is historical reference material only: its vendor records and manufactured OpenAPI files require revalidation against authoritative vendor sources before any reuse.

The separate private repository `rrunolfson/Last-Mile-Integrations` contains ServiceNow Store application source organized by OEM. It was inventoried but not transferred, archived, or altered in this phase because repository ownership changes require a separate explicit decision.

Any future restoration to a public surface requires founder approval, a current product decision, IP review, and source validation.
