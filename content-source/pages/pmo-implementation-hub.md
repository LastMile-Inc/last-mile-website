# PMO Implementation Hub Page Contract and Copy

## Job

Give implementation PMOs, OT leads, and operating sponsors a reference planning page for phased Last Mile rollout. Keep the page in the Resources area and preserve the canonical four-product public model.

## Hero

**Eyebrow:** Implementation Planning

**H1:** PMO Implementation Hub for a phased Last Mile rollout.

**Body:** Model the operator load, sequence the implementation waves, and stage a governed parallel-run without expanding the site's public product model.

**Support:** Last Mile Synapse is the implementation label for the open-protocol edge gateway workstream that stages source acquisition for Infinit-Signal during rollout.

## Required disclosure

Render this exact wording on the page:

> Reference implementation planning pages may present phased rollout models, staffing estimates, and parallel-run governance as planning aids rather than customer commitments.

## Calculator section

Render two interactive calculators:

1. **Operations-response FTE model**
   - sites in program
   - qualified conditions per site per week
   - minutes spent qualifying each condition today
   - escalation rate
   - minutes spent coordinating escalated work today
   - guided-response coverage
2. **Rollout staffing model**
   - rollout waves
   - source systems per site
   - parallel-run weeks per wave
   - shift-handoff reviews per site

Each calculator must show derived summary cards and label the output as a reference planning model.

## Phase timeline

Render a selectable phase model with these five phases:

1. Mobilize
2. Instrument
3. Parallel run
4. Guided wave
5. Scale

Each selected phase must show focus, workstreams, key deliverables, and exit gates.

## Synapse parallel-run schema

Render a selectable schema with at least four modes:

1. Mirror source evidence
2. Reconcile mappings
3. Govern assisted response
4. Cut over with verification

Each selected mode must show the current stack, Last Mile Synapse, Singularity and SSOM, and response-governance columns.

## Delivery workstreams

Explain the four delivery tracks:

- source onboarding
- canonical mapping
- workflow and authority
- site readiness
